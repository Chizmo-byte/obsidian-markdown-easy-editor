# Markdown Easy Editor

Markdownの記法をワンクリックで適用できるツールバーと、AIチャット（ChatGPT・Claude等）からコピーした乱れたMarkdownを整えてくれる「最適化」コマンドを備えた、軽量なObsidianプラグインです。

## 機能

### 📝 記法パレット（ツールバー）

リボンの鉛筆アイコンをクリックすると、サイドパネルにMarkdown記法のボタン一覧が開きます。

- **見出し** — H1〜H6
- **基本** — 太字・斜体・リスト・番号リスト・引用・リンク
- **その他** — インラインコード・コードブロック・表・チェックリスト・区切り線

各ボタンは、現在のノートで選択中のテキストに記法を適用します（未選択の場合はカーソル位置にテンプレートを挿入）。記法を覚えたり手で記号を入力する必要がありません。

### ✨ 選択範囲のMarkdownを最適化

テキストを選択した状態でコマンドパレットから「Optimize Selected Markdown（選択範囲のMarkdownを最適化）」を実行すると、Obsidian向けに書かれていないMarkdown（例：AIアシスタントの回答からコピーしたテキストなど）によくある問題を整えます。

- 行末の余分な空白・過剰な空行を削除
- 見出しの前後に空行を追加し、体裁を統一
- リストマーカーの間隔を正規化（`-項目` → `- 項目`）
- `---`・`***`・`___`のような区切り線の連続を1本に整理
- AIが生成する冒頭の前置き文（「承知しました、以下に...」等）を除去
- Obsidian特有の記法（`[[wikilink]]`・`^ブロック参照`）を通常のテキスト・リンクに変換
- コールアウト記法（`> [!note]`）を正規化
- 1行内で太字が過剰に使われている場合は強調を減らす
- 用途に応じて表を箇条書きリストに変換（オプション）

AIが生成した文章・Web記事のコピー・他ツールからのMarkdownを日常的にObsidianへ貼り付けている方に向けたプラグインです。

## 使い方

1. 左側リボンの鉛筆アイコンをクリックして記法パレットを開く、または
2. ノート内でテキストを選択し、コマンドパレット（`Ctrl/Cmd + P`）から「Optimize Selected Markdown」を実行

## コマンド一覧

| コマンド | 説明 |
|---|---|
| Show status | プラグインが正常に読み込まれているか確認 |
| Optimize Selected Markdown | 選択中のテキストを整形する |

## インストール方法

### コミュニティプラグインから（審査通過後）

1. **設定 → コミュニティプラグイン** を開く
2. 「Markdown Easy Editor」を検索
3. **インストール** → **有効化**

### 手動インストール

1. [最新のリリース](https://github.com/Chizmo-byte/markdown-easy-editor/releases)から `main.js`・`manifest.json`（あれば`styles.css`も）をダウンロード
2. `<Vaultフォルダ>/.obsidian/plugins/markdown-easy-editor/` にコピー
3. Obsidianを再読み込みし、**設定 → コミュニティプラグイン** で有効化
